# Contributing

1. Open an issue describing the change or bug.
2. Keep networking behavior aligned with official Android APIs.
3. Do not claim bandwidth aggregation unless a client/server path has been tested end to end.
4. Do not commit credentials, signing keys, user traffic, or private network information.
5. Run `gradle assembleDebug` and `gradle testDebugUnitTest` before submitting a pull request.
6. Describe device and Android-version testing in the pull request.

Contributions that add VPN routing or packet processing require a security and privacy review.
